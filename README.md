# Internet speed test

Небольшой консольный скрипт на Node.js, который 10 раз последовательно скачивает ресурс и ждёт полного получения каждого ответа.

## Требования

- Node.js 18 или новее

## Запуск

```bash
npm start -- https://example.com/image.jpg
```

или напрямую:

```bash
node index.js https://example.com/image.jpg
```

Скрипт поддерживает `http://` и `https://`, следует редиректам и завершает отдельный запрос по таймауту 30 секунд.

## Результат

В консоли выводятся:

- время каждого запроса и количество полученных байт;
- среднее время запроса за 10 измерений;
- общий объём скачанных данных;
- средняя скорость скачивания за все 10 последовательных запросов.

Скорость указана в десятичных `bit/s`, `kbit/s`, `Mbit/s` или `Gbit/s`: `1 Mbit/s = 1 000 000 bit/s`. Она считается как `общий объём в битах / общее время всех запросов`.

Для воспроизводимого замера лучше использовать URL большого файла, чтобы время установления соединения меньше влияло на результат.
